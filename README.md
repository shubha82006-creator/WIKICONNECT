# WikiConnect

## Problem
Wikipedia articles contain valuable information, but users find it difficult to explore related topics.

## Solution
WikiConnect is a Python desktop application that searches a Wikimedia article and displays its summary, categories, and related articles.

## Technologies
- Python
- Pandas
- Tkinter
- Wikimedia Structured Dataset

## Features
- Search article
- Display summary
- Show categories
- Show related articles
- Easy navigation
